Detailed Description

Simple named-section timer for ad-hoc profiling anywhere in the project - call start(label) before a section of code and stop(label) after, from as many places/threads as you want.

Safe to call start/stop for the SAME label concurrently from multiple threads (each thread tracks its own in-flight start times), the accumulated stats (total time, call count) are aggregated globally.

Usage: Timer::start("terrainGen"); ... Timer::stop("terrainGen"); // returns this call's elapsed seconds, adds it to the running total

Timer::logAll(); // dumps every recorded label's stats via VoxisLog::info
